# ✨ Citation du jour

Une page web toute simple, en **un seul fichier HTML** (HTML + CSS + JavaScript inline), qui affiche une citation inspirante aléatoire à chaque clic.

## 🎮 Démo

Ouvre simplement `index.html` dans ton navigateur — aucune installation, aucune dépendance.

## ✨ Fonctionnalités

- 💬 20 citations inspirantes tirées au sort
- 🔁 Jamais deux fois la même citation d'affilée
- 🎨 Petit effet de fondu à chaque changement de citation
- 🌙 Thème clair / sombre, avec choix mémorisé (`localStorage`) et détection de la préférence système
- 📋 Bouton pour copier la citation affichée dans le presse-papiers
- 🐦 Bouton pour partager la citation sur X (Twitter)
- 📱 Mise en page responsive, centrée, avec un joli dégradé de fond

## 🛠️ Technologies

- HTML5 / CSS3 / JavaScript (vanilla), tout dans un seul fichier pour rester simple
- `localStorage` pour mémoriser le thème choisi
- API `navigator.clipboard` pour la copie

## 🚀 Lancer le projet

```bash
git clone https://github.com/tianairiela/citation-du-jour.git
cd citation-du-jour
# puis ouvre index.html dans ton navigateur
```
